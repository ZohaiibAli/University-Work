# Lab OEL Solutions

Final lab OEL tasks for juniors. Reference ke liye use karo, copy-paste mat karo.

## Structure

```
Subject-Name/
└── Section-B/
    ├── OEL-01/   (code, .txt, ya jo bhi files)
    └── OEL-02/
```

Har subject ka apna folder, uske andar section, phir har OEL ka folder.

## Naya task add karna
1. Subject folder banao (ya existing use karo), e.g. `Data-Structures`
2. Andar `Section-B` folder
3. Andar `OEL-01` folder aur apni files daal do
4. Chaho to OEL folder mein problem statement `.txt` file add kar do
